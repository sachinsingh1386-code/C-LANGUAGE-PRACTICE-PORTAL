5. Iterative Loops - Nested Loops (1 Question)
1. Write a program print the pattern on the screen i.e. 11111 on first line and 1111111111 on second line ?
Code:
#include <stdio.h>
#include <conio.h>

void main()
{
    int i,j;
    clrscr();
    for(i=1;i<=5;i++)
    {
        printf("1");
    }
    printf("\n");
    for(j=1;j<=10;j++)
    {
        printf("1");
    }
    printf("\n");
}
Output:
11111
1111111111
